# Aetheris Initiative

Concept site for the Aetheris Initiative, a fictional planetary-restoration utility: a space elevator anchored
at an ocean mega-city, an L1 sunshade, Angel-class seeding gliders and Leviathan-class ocean harvesters.
The page includes a live isometric 3D model of the whole operation (Three.js).

Everything is fictional and the telemetry is simulated.

## Run locally

```
python -m http.server 4392
```

Then open http://127.0.0.1:4392/. The whole site is one file, `index.html`.
