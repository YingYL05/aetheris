# Aetheris Initiative

Concept site for the Aetheris Initiative, a fictional planetary-restoration utility: a space elevator anchored
at an ocean mega-city, an L1 sunshade, Angel-class seeding gliders and Leviathan-class ocean harvesters.
Four pages: a plain-language home, a live isometric 3D model of the whole operation (Three.js), how the
technology works, and the Accord with its open data.

Everything is fictional and the telemetry is simulated.

## Run locally

```
python -m http.server 4392
```

Then open http://127.0.0.1:4392/. Pages: `index.html`, `model.html`, `technology.html`, `accord.html`, with shared
`assets/site.css` and `assets/site.js`.
